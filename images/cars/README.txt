Put the real car photos in this folder, using EXACTLY these file names (.jpg):

  toyota-corolla-cross.jpg
  honda-civic.jpg
  tesla-model-3.jpg
  jeep-wrangler.jpg
  mini-cooper.jpg
  hyundai-tucson.jpg

Tips
- Side/front-three-quarter shots on a plain or clean background look best (cards use object-fit: contain, ~600x400 px is plenty).
- Use photos you have the right to use: Wikimedia Commons (commons.wikimedia.org, check each licence), Unsplash, Pexels, or manufacturer press kits.
- If a file is missing, the site automatically falls back to the old illustration (images/car-*.svg), so nothing breaks.
- Cars added later from the admin dashboard use the same rule: images/cars/<make>-<model>.jpg
  (lowercase, spaces become hyphens, e.g. "Kia Seltos" -> kia-seltos.jpg).
